# 绘图工坊 0.3.9

插件使用酸薄荷接口，配合本仓库宿主支持聊天图片导入、原图保存、独立 Vibe 氛围参考和精准参考。原插件 ID `com.nanzhi.naistudio`、配置键 `nai.studio.v2` 保持一致，覆盖导入即可保留配置。

安装包只需要 `main.js`、`manifest.json`、`ui/` 三项。不要把测试、报告、宿主补丁或 API Key 放入安装包。宿主能力随 APP 更新，不能通过导入插件 ZIP 安装。

## 使用

- 默认配置只有页面明确保存时改变。AI 调用的 `overrides` 是单次覆盖，可通过 `vibe_enabled:false`、`precise_enabled:false` 明确关闭参考。预设改名/删除会同步修复配置引用。
- AI 先调用 `nai_chat_image(action=list)`，再通过返回的 `attachment_id` 导入当前聊天分支的用户图片。本地素材编号可分别用作图生图底图、Vibe 或精准参考；不要求传图片编码。
- 手机选图、预览、替换、移除和开关在各用途区域独立。选择参考不会切换图生图模式。四组参数可折叠，试画与预览在预设管理前。
- 参考能力仅开放已核实的 V4.5 Full/Curated 原生通道，最多各 16 张；Vibe 与精准参考互斥，不支持的 URL/V5 或其他组合会明确报错。
- Vibe 导入与编码分开：免费检查状态后单独编码，再提交生成。缓存绑定源图内容、模型、信息提取量与预处理版本；只改参考强度可复用。未知结果不会自动重发。
- 精准参考支持角色、画风、角色与画风，以及强度和保真度；没有与人物卡绑定的虚构参数。
- `nai_draw(preview=true)` 显示最终参数、参考及编码状态，不调用平台、不扣费。页面预览与提交使用相同参数快照，手填图生图种子会保留。
- 结果通过宿主文件选择器保存原始字节，取消不报成功。生成结果读取或本地存储失败不会误报成功，也不会重新发起该任务。
- 放大函数和页面流程保留原实现。手动向聊天发送底图保留工具，自动共看带图继续关闭工具。

## 费用和验证范围

平台文档/部署页面给出的参考附加估算：Vibe 编码 2 Anlas/张，Vibe 超过 4 张后生成每张附加 2 Anlas，精准参考生成附加 5 Anlas/张。基础生成、积分倍率和套餐另算，以平台实际扣费为准。

本地 30 项插件模拟回归、269 项 app 和 122 项 AI 回归通过，ARM64 测试 APK 编译及签名核验通过；用户反馈该测试版效果很好。未取得可用 Key，未进行真实付费参考接口联调，不能将模拟测试视为线上扣费或全部参考效果验收。

运行插件回归：`node --test plugins/image-atelier/tests/references.test.cjs`。测试包含原放大代码 SHA256 校验，修改时不要调整校验值掩盖实现变化。
